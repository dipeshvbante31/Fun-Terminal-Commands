🎉 Fun Terminal Pranks

A collection of harmless and funny PowerShell terminal pranks for Windows.

These scripts are designed for jokes with friends and learning PowerShell. They only display text/progress, generate random numbers, show ASCII art, or make console beeps.

🚀 Quick Start

Clone the repository:

git clone YOUR_REPOSITORY_URL
cd fun-terminal


Run the script:

.\fun-terminal.ps1


If PowerShell blocks the script, you can run it for the current PowerShell session with:

Set-ExecutionPolicy -Scope Process Bypass


Then:

.\fun-terminal.ps1

🛑 Stopping a Prank

If a command keeps running, press:

Ctrl + C


to stop it.

🔒 Safety

This project is intentionally harmless.

It does not:

Delete files
Modify or encrypt files
Steal passwords or credentials
Install malware
Create persistence
Shut down or damage computers
Attack networks or other systems

Use it only on computers where you have permission to run scripts.
